# 📊 Customer & Marketing Analytics Dashboard

An end-to-end analytics dashboard analyzing *10,000+ customer records* across demographics, purchase behavior, and marketing campaign performance.

## 🚀 Project Overview

This project helps businesses understand customer behavior, identify high-value customers, evaluate marketing campaigns, and support data-driven business decisions.

---

## 🎯 Business Objectives

- Analyze customer demographics
- Identify top-performing customer segments
- Track sales and revenue
- Measure campaign effectiveness
- Generate business recommendations

---

## 🛠️ Tools Used

- Power BI
- SQL
- Microsoft Excel
